```uv init``` # Initialize a new virtual environment
```uv v .venv``` # Activate the virtual environment
```uv add -r requirenment.txt``` # Install the required packages
```uv add library name``` # Add a new library to the virtual environment
```uv remove library name``` # Remove a library from the virtual environment
```uv list``` # List all installed libraries in the virtual environment
```uv run script.py``` # Run a script in the virtual environment
